\# 🖼️ AI Image or Real Image? - DeepFake Image Detection using Vision Transformers



An end-to-end \*\*AI-powered DeepFake Image Detection System\*\* built using \*\*Python, Flask, Hugging Face Transformers, Vision Transformers (ViT), and Deep Learning\*\*. The application analyzes uploaded images and predicts whether they are \*\*AI-generated (DeepFake)\*\* or \*\*Real\*\*, helping identify synthetic media created by modern generative AI models.



\---



\# 📖 Project Overview



With the rapid advancement of Generative AI technologies, distinguishing AI-generated images from authentic photographs has become increasingly challenging. DeepFake images can be used for misinformation, identity fraud, and digital manipulation, making reliable detection techniques increasingly important.



This project leverages a \*\*Vision Transformer (ViT)\*\* model to classify uploaded images as either:



\* 🟢 \*\*Real Image\*\*

\* 🔴 \*\*AI Generated / DeepFake Image\*\*



Users can upload an image through the web interface and receive an instant prediction from the trained deep learning model.
